# 🌌 3D Universe Portfolio *(Work in Progress)*

> 🚧 **Status: Under Construction — Coming Soon!**

Welcome to **Singularity 3D Universe**, an interactive 3D portfolio set in deep space. This project is currently **under active development** and builds an immersive cosmic universe featuring a real-time black hole, orbiting planets, spacecraft, satellites, and interactive flight controls.

---

## 🛠️ Technologies Used

- **[Three.js](https://threejs.org/) (`^0.160.0`) & WebGL** — Real-time 3D rendering, custom lighting, particle starfields, orbital mechanics, and interactive camera controls.
- **GLTF / GLB 3D Models & PBR Materials** — 3D assets and animations (Black Hole, Planet Earth, Spacecraft, Satellites, and Pilotable UFO).
- **JavaScript (ES6+ Modules)** — Modular architecture for scene management, entity simulation, warp effects, and manual flight physics.
- **HTML5 & CSS3 (Glassmorphism UI)** — Futuristic HUD overlays, glassmorphic navigation panels, and responsive modal interfaces.
- **[Vite](https://vitejs.dev/) (`^5.0.0`)** — Fast frontend build tool and development server.
